## Editorial choices

The first catalog selects 18 public projects to cover binary research, AI infrastructure, application security, reporting, and development. Private repositories and unpublished engagement details are excluded. This selection is not a count of all maintained tools.

The source files differ on architecture counts and service pricing. The catalog therefore uses project descriptions and unpriced engagement areas. Sponsor pricing remains managed separately.

Claims such as “first public,” “100% complete,” guaranteed security, and automatic accuracy improvements are not repeated. CVE attribution and vendor acceptance need direct supporting records before they become résumé claims. No independent attribution check has been performed as part of this build.

## Record verification

All initial records use `owner-reported`. To change a record to `verified`, inspect the linked source and record what it establishes. Add a `verification` object containing `source`, `checked_on`, and `notes`. Verification of a repository's existence alone does not verify benchmarks, findings, or customer relationships.

The original source documents are unchanged.
