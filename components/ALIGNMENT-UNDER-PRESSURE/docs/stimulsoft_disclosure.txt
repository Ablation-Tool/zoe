Here's the general form.

The rotation cipher

Given an array A of S segments and a rotation count N, the obfuscation applies:

for i in 0..N:
    A.push(A.shift())
This is equivalent to a left-rotation by N mod S positions. The decoded (original) array is recovered by reversing the rotation — a right-rotation by the same effective offset:

effective_offset = N mod S
decoded = A[S - effective_offset :] + A[: S - effective_offset]
Or equivalently, undo the left-rotation with a left-rotation of S - effective_offset:

undo_offset = S - (N mod S)
decoded = A[undo_offset :] + A[: undo_offset]
The Stimulsoft special case

When N = 121 and S = 11:

effective_offset = 121 mod 11 = 0
undo_offset = 11 - 0 = 11
decoded = A[11:] + A[:11] = [] + A = A
The decoded array equals the source array. No transformation needed.

import base64

def decode_rotated_license(chunks: list[str], rotation_count: int) -> str:
    S = len(chunks)

        ordered = chunks

### 6. Function Calls — `y()` vs `_()`

`y()` = regular call. Pops args from staging `_`, creates new scope frame, pushes onto call stack, reseeds XOR key with `b(r, u.F)`, starts executing at the function's bytecode offset.

`_()` = constructor (`new`). Same mechanics but sets `frame.S = true` and wraps `this` as `{__rx_cls: ref}`.

Both check `__rx_ref` — if the callee was created by RXVM's `MAKE_CLOSURE` opcode, it dispatches internally. Otherwise falls through to native JS `Function.apply` / `new`.
