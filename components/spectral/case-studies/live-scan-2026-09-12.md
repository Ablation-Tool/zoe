## Analysis

### The test-cassette inflation problem

The dominant noise source across all four AI framework repos is AGT-002 (`claude_agent_session_transcript`). The pattern matches on `conversation_id` + `message_start` event payloads from the Anthropic streaming API. All four frameworks record live API responses into VCR cassettes or test fixture JSON files during integration tests. These files contain verbatim API response bodies that match the signature exactly.

crewAI shows this most clearly: 1261 raw findings drop to 81 with `--skip-tests` (-94%). The remaining 81 are real artifact hits in the production source tree.

The `--skip-tests` flag addresses this by pruning directories named `test`, `tests`, `__tests__`, `fixtures`, `cassettes`, `vcr_cassettes`, `recordings`, `snapshots`, `__snapshots__`, `testdata`, `test_data` from the walk before any content scanning.

**Guidance:** Use `--skip-tests` when scanning a codebase for AI usage in production code. Omit it when you want to enumerate what AI APIs the project tests against - that is itself useful intel.

### crewAI self-matches AGT-030

AGT-030 (`crewai_task_artifacts`) matched 55 times in crewAI's own lib tree against production source files. The signature pattern matches the output format that crewAI generates at runtime. This is a strong signal that the pattern is correctly tuned - the framework's own code produces artifacts that match the signature.

### AutoGPT is the most Claude-heavy

AutoGPT's monorepo contains 13 `CLAUDE.md` project config files (AGT-001) and 71 session transcript hits - more than any single other repo after test-stripping. The CLAUDE.md files confirm that AutoGPT is actively developed using Claude Code across multiple subpackages.

### Pre-AI repos hit on real AI adoption

Both hits in the pre-AI corpus were true positives. tmux has a Copilot configuration for contributor assistance. Redis's new vector-sets module ships Ollama integration examples. These are signal, not noise: spectral correctly identifies where AI tooling has been introduced into mature codebases.
