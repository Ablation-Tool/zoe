# Provenance

Neurogarden is preserved directly inside **Ablation-Tool/zoe** at Nicholas Michael Kloster's direction: the logging system belongs in Zoe.

The original project was `nuclide-research/agent-logging-system`, an OT/ICS-inspired operational monitor for multi-agent systems. That GitHub repository was deleted and is no longer available for fetching. The local Git object store also lacks a usable HEAD and complete historical objects. No upstream revision is invented or inferred.

This tree preserves the available package, license, documentation, examples, and source tests, followed by Neurogarden integration work:

- Trinity mobile/Q0.15/APDU verification with idempotent revisions and original-equation credit.
- Bounded review queues, cited reading observations, and explicit non-authorization of clinical action.
- Needleman–Wunsch and imaging-sampling teaching instruments derived from specifically cited reading.
- Extracted-library metadata cataloging with intentional folder/title mismatch preservation.
- CERN evidence, Allen atlas geometry, neural-signal analysis, and a generative world with review-required experiments.
- Bounded affine/log-Euclidean SPD operations, a perfusion-stable Pennes teaching model, and neutrosophic membership similarity with three additional source-linked chapter reviews.
- Complete BioCoder, Summer 2014 article reviews with current-SDS chemical guidance, idealized read-overlap geometry, and explicit hardware/wet-lab no-tool boundaries.
- Complete BioCoder, Winter 2014 article reviews with an exploratory abundance-ratio teaching tool and explicit treatment, legal, organism-welfare, and tissue-processing boundaries.
- Complete GPT-3 review across all eight substantive sections, with explicit artifact exclusions, offline prompt and programming-request tools, an AI deployment checklist, and startup/enterprise/conclusion no-tool rationales.
- MATLAB Numerical Calculations introduction and chapter 1 review, with exact bounded integer-complex exponentiation.
- QKD/post-quantum pairing audit with NIST and NSA sources, explicit current-algorithm vulnerability, and a hybrid research path rather than an implemented migration.
- Version 0.6.8 packaging and focused verification.

Unrelated network-scan directories, `empire.db`, Git metadata, caches, and temporary build artifacts were not imported. The component remains an inspectable Python library, not a background agent, external collector, clinical authority, or autonomous execution service.
