# Nicholas Kloster

Independent security researcher and tool builder

nicholas@nuclide-research.com | https://nuclide-research.com

I investigate AI infrastructure, applications, and firmware. I build tools to test security assumptions, trace software behavior, and document findings that other researchers can reproduce.

## Selected work

### [Ablation](https://github.com/Ablation-Tool/ablation)

Analyze compiled software with a framework for binary lifting, data-flow analysis, semantic search, and persistent research findings.

Methods: disassembly, taint analysis, hypothesis testing, cross-target pattern reuse.

### [Ablation Case Studies](https://github.com/francis-rancid/Ablation-Case-Studies)

Publish investigations that connect analysis output to the evidence used to assess findings.

Methods: case studies, evidence review, reproduction.

### [RXVM](https://github.com/Nicholas-Kloster/RXVM)

Reconstruct the bytecode interpreter and neural-network structure of a client-side bot detection system.

Methods: bytecode analysis, protocol reconstruction, behavioral analysis.

### [aimap](https://github.com/nuclide-research/aimap)

Identify AI services and enumerate exposed inference servers, vector databases, and supporting infrastructure.

Methods: service fingerprinting, endpoint enumeration, exposure assessment.

### [gatecheck](https://github.com/nuclide-research/gatecheck)

Test whether inference gateways enforce authentication under altered headers, tokens, and request paths.

Methods: authentication testing, header probes, path normalization testing.

### [herald](https://github.com/nuclide-research/herald)

Run declarative HTTP probes to check authentication across individual routes.

Methods: route coverage, HTTP probes, declarative test configuration.
